# Fluent Music QMusic Plugin

## 支持的功能

- QQ 音乐扫码登录、登录状态查询、账号资料、会话恢复及注销。
- 歌曲搜索、个人歌单、完整歌单歌曲分页与歌曲信息。
- 游客推荐、本人账号推荐、Flyme 首页与歌单推荐。
- 多音质目录、音质选择、已授权歌曲播放及 QMC v2 音频处理；不绕过会员或版权限制。
- LRC / QRC 歌词、逐字时间与翻译歌词。
- Fluent Music API / C ABI 2 原生插件、宿主文件与网络接口及 Windows DPAPI 会话保护。
